# Glamour v0.1 — Living Canvas (Rung 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** Grow Glamour from a state-driven animation format into an AI-authorable *interactive canvas* — the job Rive does in the host app — by adding continuous motion, free wander, node groups, and a host-driving API. Logic stays in the host (React); Glamour owns motion + input surface.

**Architecture:** Additive layer over v0 (schema id becomes `glamour/v0.1`; every v0 doc stays valid). Deterministic motion *math* lives in `@glam/core` (pure, headless-tested); the live `requestAnimationFrame` run-loop + host event bus live in `@glam/player` (browser). Headless `renderToPNG` renders a static resting frame (loops at `from`, wander at rest). Built on Konva (Groups, Animation) — no new heavy deps.

**Tech Stack:** unchanged — TypeScript, pnpm, Konva 9, XState 5, Vitest, Node 20 (`.nvmrc`; native canvas ABI). Run everything on Node 20.

## Global Constraints
- Additive + backward compatible: all existing 131 tests stay green; v0 docs validate unchanged.
- `glamour/v0.1` schema id accepted; `glamour/v0` also still accepted.
- ESM, TS strict, no `any` in public signatures. Commit per task; messages end with `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`. No persona names in files.
- Motion math is pure + deterministic in core (injectable RNG for wander so it's testable). The browser loop is the only non-deterministic/timing piece.

## The two proof cases (drive every design choice)
1. **Crab word-game** — a crab node slides right↔left forever (`loops` alternate on `x`); clicking the moving crab fires a host event (`emit`). Host (React) decides correct/score. Proves: continuous deterministic motion + click-on-moving-node + `player.on`.
2. **Orb (Dolli)** — a `face` **group** (eyes + mouth) that **wanders** freely in idle; host calls `player.send('SHOW_CHECK'|'SHOW_STAR'|'SHOW_HEART')` to swap the orb into feedback states (recolor + show ✓/★/♥, hide face). Proves: wander + groups + host-commanded state (`@`-events) + `player.send`.

## New format surface (`glamour/v0.1`)

```ts
type Ease = 'linear' | 'easeIn' | 'easeOut' | 'easeInOut';

interface GlamLoop {                     // continuous auto-playing motion
  node: string; prop: string;            // numeric prop (x,y,r,w,h,opacity,rotation,size)
  from: number; to: number; ms: number;
  mode?: 'loop' | 'alternate';           // default 'loop'; 'alternate' ping-pongs
  ease?: Ease;                           // default 'linear'
}
interface GlamWander {                    // free drift to random points in an ellipse
  target: string;                        // node OR group id
  cx: number; cy: number; rx: number; ry: number;
  stepMs: number; ease?: Ease;           // default 'easeInOut'
}
interface GlamGroup { id: string; x: number; y: number; }   // a Konva.Group; children opt in via node.group

// additions to GlamNode:  group?: string;  emit?: string;
// additions to GlamDoc:   schema: 'glamour/v0' | 'glamour/v0.1';  groups?: GlamGroup[];  loops?: GlamLoop[];  wander?: GlamWander[];
// machine `on` keys gain a third form: "@EVENTNAME" — a host-sent event (player.send).
```

### Task A3: pure motion math (`motion.ts`)
```ts
export function loopValueAt(loop: GlamLoop, elapsedMs: number): number; // eased, mode-aware
export class Wander {                    // deterministic with injected rng
  constructor(w: GlamWander, rng: () => number);   // starts centered at (cx,cy)
  valueAt(elapsedMs: number): { x: number; y: number };   // advances targets internally by time
}
```
- `loopValueAt`: **`ms` is the full round-trip period.** For `alternate`, a triangle wave over `ms` — phase 0→1 across `[0, ms/2]` then 1→0 across `[ms/2, ms]` (peak at `ms/2`); for `loop`, a sawtooth 0→1 over `ms` (wraps). Apply `ease` to the 0..1 phase, then lerp `from`→`to`.
- `Wander`: first target is the ellipse center `(cx,cy)`; `valueAt(t)` eases within the current segment (prev→target over `stepMs`); when a segment completes it samples the next target and continues. **Ellipse sampling — exact formula (two `rng()` draws per target):** `a = 2π·rng()`, `rad = √(rng())`, `target = (cx + rad·cos(a)·rx, cy + rad·sin(a)·ry)` (uniform in the ellipse disk).
- [ ] failing tests: `loopValueAt({from:0,to:100,ms:1000,mode:'alternate'}, 500)` ≈ 100 (peak at ms/2); at 1000 ≈ 0; `loop` mode: value at `ms` wraps to `from`. `Wander` at `t=0` is `(cx,cy)`; feed a scripted `rng` sequence and assert every sampled target satisfies `((x-cx)/rx)² + ((y-cy)/ry)² ≤ 1 + 1e-9` across ≥20 steps; a target whose radius-draw is `0` lands exactly at `(cx,cy)`.
- [ ] fail → implement → pass → commit `feat(core): pure loop + wander math`.
